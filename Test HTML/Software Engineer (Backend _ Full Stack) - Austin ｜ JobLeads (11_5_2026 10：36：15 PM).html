Job description

Software Engineer (Backend / Full Stack) : Entry-Level / Junior (0-3 Years)

Employment Type: Full-Time

Experience: 0-3 Years

Compensation: $75,000-$120,000/year (depending on experience, location, and technical skills)

About This Opportunity

Amoha Recruitment Services LLP is building a talent pipeline of junior Software Engineers for upcoming client opportunities across backend development, full-stack engineering, and software product development.

We work with candidates on OPT, STEM-OPT, and H-1B status, as well as US citizens and Green Card holders, subject to individual client and employer requirements.

This opportunity is designed for recent graduates and early-career professionals who are interested in exploring full-time Software Engineering roles with our client companies.

What You'll Do
  • Develop, test, and maintain backend applications and software services.
  • Build responsive, user-friendly web applications and interfaces.
  • Design and integrate REST APIs and backend services.
  • Work with databases, including SQL and NoSQL systems.
  • Collaborate with frontend developers, QA engineers, and product teams.
  • Write clean, scalable, and maintainable code.
  • Troubleshoot bugs, optimize performance, and improve application reliability.
  • Participate in code reviews, testing, and software development processes.
  • Work with cloud platforms and deployment tools as required.
Required Qualifications
  • Bachelor’s or Master’s degree in Computer Science, Software Engineering, Information Technology, or a related field.
  • 0-3 years of experience in software development, including internships, projects, or relevant coursework.
  • Understanding of data structures, algorithms, and object-oriented programming.
  • Basic knowledge of backend frameworks such as Spring Boot, Node.js, Django, or .NET.
  • Familiarity with REST APIs, SQL databases, and Git.
  • Strong analytical, communication, and problem-solving skills.
Skills That Strengthen Your Application
  • React, Angular, or Vue.js
  • Java, Spring Boot, Node.js, Python, or .NET
  • PostgreSQL, MySQL, MongoDB, or SQL Server
  • AWS, Azure, or Google Cloud
  • Docker, Kubernetes, and CI/CD fundamentals
  • Automated testing frameworks and debugging tools
Work Authorization

  • Candidates on F-1 OPT or STEM-OPT
  • Candidates eligible for or currently holding H-1B status

Work authorization and sponsorship eligibility will depend on the specific client and position requirements.
